# OpenHands Monitor Bot

## Описание проекта

OpenHands Monitor Bot — это Telegram-бот, предназначенный для мониторинга задач на платформе OpenHands и отправки уведомлений в реальном времени об изменениях статуса задач. Он непрерывно опрашивает API OpenHands для получения обновлений о беседах/задачах и оповещает пользователей о:

- **Новых задачах**, которые создаются
- **Изменениях статуса** (например, с "running" на "completed")
- **Завершении задач**

Этот бот помогает командам быть в курсе своих задач OpenHands без необходимости постоянно проверять платформу вручную.

### Ключевые возможности
- **Мониторинг в реальном времени**: Непрерывно опрашивает API OpenHands для получения обновлений задач
- **Уведомления в Telegram**: Отправляет мгновенные оповещения в настроенный чат Telegram
- **Отслеживание статуса**: Сохраняет состояние для обнаружения изменений между циклами опроса
- **Обработка ошибок**: Грациозно обрабатывает ошибки API и проблемы с сетью
- **Настраиваемый опрос**: Регулируемый интервал для проверки обновлений

## Инсталляция

### Шаг 1: Клонирование репозитория

Клонируйте репозиторий на ваш локальный компьютер:

```bash
git clone https://github.com/bughouse-wizzard/openhands-monitor-bot.git
cd openhands-monitor-bot
```

### Шаг 2: Установка зависимостей

Установите все необходимые пакеты Python с помощью pip:

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения

Создайте файл `.env` в корне проекта с необходимыми переменными окружения:

1. **Скопируйте пример файла окружения:**
   ```bash
   cp .env.example .env
   ```

2. **Отредактируйте файл `.env`** с вашей конфигурацией (подробности см. в разделе Конфигурация ниже):
   - `TELEGRAM_TOKEN` - Токен вашего Telegram-бота (обязательно)
   - `CHAT_ID` - ID вашего чата Telegram (обязательно)
   - `OPENHANDS_API_URL` - URL вашего API OpenHands (опционально, по умолчанию `http://host.docker.internal:3000`)

## Использование

Чтобы запустить OpenHands Monitor Bot, выполните:

```bash
python bot.py
```

Бот будет:
1. Проверять, что все необходимые переменные окружения установлены
2. Отправлять уведомление о запуске в ваш чат Telegram
3. Начинать опрашивать API OpenHands с настроенным интервалом
4. Отправлять уведомления о новых задачах и изменениях статуса

## Конфигурация

Бот требует установки следующих переменных окружения в файле `.env`:

### Обязательные переменные окружения

- **`TELEGRAM_TOKEN`**: Токен API вашего Telegram-бота (получите у [@BotFather](https://t.me/botfather))
- **`CHAT_ID`**: ID чата Telegram, куда будут отправляться уведомления

### Опциональные переменные окружения

- **`OPENHANDS_API_URL`**: Базовый URL для API OpenHands (по умолчанию: `http://host.docker.internal:3000`)
- **`POLL_INTERVAL`**: Интервал опроса в секундах (по умолчанию: `5`)

### Пример файла `.env`

```env
# Обязательные переменные
TELEGRAM_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
CHAT_ID=987654321

# Опциональные переменные
OPENHANDS_API_URL=http://localhost:3000
POLL_INTERVAL=5
```

**Примечание**: В инструкциях задачи упоминаются `TELEGRAM_BOT_TOKEN` и `OPEN_HANDS_API_URL`, но фактический код использует `TELEGRAM_TOKEN` и `OPENHANDS_API_URL`. Используйте имена переменных, указанные выше, для правильной работы.

## Описание API

### Основные функции

#### `send_telegram_message(message: str) -> bool`
**Расположение**: `bot.py`

**Описание**: Отправляет сообщение в настроенный чат Telegram.

**Параметры**:
- `message` (str): Текст сообщения для отправки.

**Возвращает**:
- `bool`: True, если сообщение успешно отправлено, False в противном случае.

**Обработка ошибок**:
- Повторяет попытку 3 раза с задержкой 2 секунды
- Логирует ошибки при неудаче
- Вызывает исключение после исчерпания попыток

#### `fetch_conversations() -> list[dict]`
**Расположение**: `bot.py`

**Описание**: Получает беседы из API OpenHands.

**Параметры**: Нет

**Возвращает**:
- `list[dict]` или `[]`: Список бесед или пустой список при ошибке.

**Обработка ошибок**:
- Грациозно обрабатывает HTTP-ошибки
- Возвращает пустой список при сбоях сети
- Логирует детали ошибок

#### `poll_and_notify() -> None`
**Расположение**: `bot.py`

**Описание**: Основной цикл опроса для мониторинга бесед.

**Параметры**: Нет

**Возвращает**: Нет (работает бесконечно)

**Поведение**:
- Опрашивает API с настроенным интервалом
- Сравнивает текущее состояние с предыдущим
- Отправляет уведомления об изменениях
- Очищает старые состояния бесед

#### `main() -> None`
**Расположение**: `bot.py`

**Описание**: Основная точка входа для OpenHands Monitor Bot.

**Параметры**: Нет

**Возвращает**: Нет

**Поведение**:
- Проверяет переменные окружения
- Отправляет уведомление о запуске
- Запускает цикл опроса
- Обрабатывает корректное завершение работы

### Модуль словаря (`map_maker.py`)

#### `get_definitions(word: str, custom_dict: dict = None) -> list`
**Описание**: Получает определения слова из словаря.

**Параметры**:
- `word` (str): Слово для поиска. Автоматически преобразуется в строку, если еще не является строкой.
- `custom_dict` (dict, опционально): Пользовательский словарь для использования вместо стандартного словаря.

**Возвращает**:
- `list`: Список определений. Пустой список, если слово не найдено.

**Примеры**:
```python
from map_maker import get_definitions

# Поиск в стандартном словаре
definitions = get_definitions("apple")
# Возвращает: ['A fruit that grows on trees', 'A technology company founded by Steve Jobs']

# Поиск в пользовательском словаре
custom_dict = {"python": ["Мой любимый язык программирования"]}
definitions = get_definitions("python", custom_dict)
# Возвращает: ['Мой любимый язык программирования']

# Слово не найдено
definitions = get_definitions("nonexistent")
# Возвращает: []
```

**Обработка ошибок**:
- Входные данные не-строки преобразуются в строки
- Пустые строки возвращают пустые списки
- Значения None преобразуются в строку "none"
- Возвращает копию списка для предотвращения изменения оригинального словаря

Стандартный словарь (`STANDARD_DICTIONARY`) содержит:

| `openhands` | "A platform for AI development and collaboration" |
